2. How to Generate a Final Score Probability Matrix

Every market in this project starts from the same foundation: a Home × Away scoreline probability matrix. This section builds that matrix from scratch using a simple 10-match history.

2.1 Exercise 1 — Historical Match Data

Start with the last 10 matches. Count how often each goal value occurs for the Home and Away teams, then convert those counts into probabilities:

Probability = Goal Count ÷ Number of Matches

2.2 Exercise 2 — Final Score Probability Matrix

Use the Home and Away goal probabilities from 2.1 to build a joint scoreline probability matrix:

P(Home = h, Away = a) = P(Home = h) × P(Away = a)

This matrix becomes the starting point for every market in Section 3.

For this simplified exercise, Home and Away goals are assumed to be independent. Under this assumption, the probability of both outcomes occurring is the product of their individual probabilities.

This is a modeling simplification. In real matches, the two teams' scoring outcomes can influence each other.
